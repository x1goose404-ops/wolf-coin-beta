Root causes fixed
  a) Wallet detection: Wallet-Standard-only discovery did not surface X1 Wallet. Replaced with the
     verified theo-sign approach: window.x1Wallet first (provider.isX1Wallet), then window.backpack/window.xnft;
     connect() + publicKey.toString(); sign via signAndSendTransaction(VersionedTransaction) [X1] or
     signTransaction + sendRawTransaction(...,{skipPreflight:true}) [Backpack].
  b) CSS: .modal{display:flex} / .card{display:flex} overrode the [hidden] attribute, so the confirm
     dialog and wallet card leaked visibly. Fixed with `[hidden]{display:none !important}` and guarded by
     a browser assertion.
  c) Deploy: this host has no git-remote-https, so git push cannot work -> deploy via the GitHub REST API.
  d) The archived deploy script targeted a MIS-NAMED repo (literal "wolf-c" + U+2026 + "site"); the clean
     repo is x1goose404-ops/wolf-coin-beta.
